🔄 跨裝置雲端同步

不同網域、不同瀏覽器、不同 IP、不同裝置 → 全自動同步連動。不需 API key、不用手動輸入同步碼。

☁️ 雲端自動同步（免設定）

同步狀態
正在啟動…
  • ✅ 開啟即同步 — 換網域、換瀏覽器、換手機、換電腦，打開網頁自動連上，不必輸入任何代碼。
  • ✅ 即時推送 — 同事改了客戶或商機，你的畫面會自己更新（不需要重整）。
  • ✅ 雙向合併 — 兩台裝置同時改資料不會互相覆蓋；刪除的資料也不會被別台「復活」。
  • ✅ 離線可用 — 斷網時照常操作，資料存在本機，恢復連線後自動補同步。
  • 🔒 資料以 gzip 壓縮 + AES-GCM 加密後傳輸，不以明文暴露。

同步空間：—（本團隊專屬頻道，已內嵌，無需手動輸入）

📋 剪貼簿一鍵同步

把目前所有資料壓縮成同步碼，按一個鈕複製到剪貼簿；到另一台裝置貼上即可同步。

📁 JSON 檔案備份 / 還原

完整資料備份到 JSON 檔案（可上傳到雲端硬碟 / Email / WeChat 傳送給自己）。

🔗 微型連結分享（單筆商機）

把任一筆商機打包成網址，傳給同事直接打開就能查看完整資訊。

👤 我是哪個業務？

點名字可切換身份；滑到成員右側 🗑 可刪除業務。刪除成員不會刪掉他名下的資料（負責人欄位保留），只是無法再用該身份登入。
